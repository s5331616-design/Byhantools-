# Byhantools - Android Device Utilities

<p align="center">
  <b>أدوات Android لمعلومات الجهاز وخدمات Google واختصارات النظام.</b><br>
  <i>An Android utility for device information, Google Services settings, and system shortcuts.</i>
</p>

---

## 🌟 المميزات الرئيسية (Features)

- عرض طراز الجهاز وإصدار Android.
- عرض نوع اتصال الشبكة مع إمكانية تحديث الحالة.
- اختصارات عامة لإعدادات الشبكة وإدارة التطبيقات.
- إرشاد المستخدم إلى اتباع خطوات التحقق الرسمية لدى Google.

---

## 📱 متطلبات التشغيل (Requirements)

- **نظام التشغيل**: Android 5.0 (API 21) فما فوق (يدعم Android 14 و Android 15).
- **بيئة التطوير**: Android Studio، Gradle 8.13، و JDK 17.

---

## 🛠️ البناء والتثبيت (Build & Installation)

لبناء ملف الـ APK التجريبي (Debug APK):

```bash
# بناء نسخة الـ Debug
gradle assembleDebug
```

مسار ملف الـ APK الناتج:
`app/build/outputs/apk/debug/app-debug.apk`
